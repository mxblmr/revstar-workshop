# Outbound skills

Eight skills, one per step of the outbound section of the workshop. Each one
reads your context layer in `./gtm-context` and stops when a file cannot
answer.

## How to use them

1. Copy this `skills/` folder into your project (for Claude Code, into
   `.claude/skills/`).
2. Open the folder that holds `./gtm-context` in Claude Code or Codex.
3. Ask for a skill by name, for example: "Run the reframe-offer skill on
   offer.md."

## Basic: when you do not have enough context yet

Run these in order. Each round teaches you something.

| Skill | What you get |
|---|---|
| `build-test-list` | 6 to 8 filters, about 3,000 accounts left |
| `reframe-offer` | an offer that makes one of the four B2B promises |
| `write-cold-email` | under 100 words, one proof, an A/B test on the ask |
| `read-the-round` | what the replies say, and the one line to fix |

## Advanced: once you have learned

Start here when the same trait keeps showing up in the yes replies.

| Skill | What you get |
|---|---|
| `find-10x-clients` | who closed fastest, and what they shared before buying |
| `find-pain-signal` | one signal only the pain produces |
| `join-sources` | the public sources that hold the list, and how to join them |
| `what-they-steal` | what only you can send, and 20 experiments to send it |
