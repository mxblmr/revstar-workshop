# Find the pain signal

Title, size and industry are filters anyone can buy, and our competitors send
on them too. A pain signal is something an account could not have unless it
lives with the problem we solve.

Example: selling a headache treatment to "neurologists" is a title. A
headache-specialty certification is a pain signal: nobody holds it without
treating headaches all day.

## Step 1. Read

`./gtm-context/icp.md`, the section "Before they bought". If it is empty, run
`find-10x-clients` first.

## Step 2. Walk back from the pain

For each trait the 10X clients shared, ask:

1. What problem does this trait prove the account has?
2. Could an account have this trait **without** that problem? If yes, it is
   not a pain signal.
3. Where does this trait leave a trace I can read from outside? A directory,
   a licence, a filing, a job post, a page on their site, a tool in their
   stack.

Then go one level deeper. Within the accounts that have the signal, is there
a sub-group that closed faster still? What did they share? (Where they
trained, who they worked under, what they already tried.)

## Step 3. Test each candidate

Keep a signal only if all three hold:

- **Only the pain produces it.** An account cannot have it by accident.
- **It can be listed by name.** There is a source that returns accounts, not
  just a description of them.
- **Our competitors are not already sending on it.** If it is a checkbox in
  a common sales database, everyone has it.

## Step 4. Size it

Estimate how many accounts carry the signal. Advanced lists are small:
hundreds, sometimes dozens. That is the point. Say the number and how you
got it.

## Step 5. Hand back

- One signal, in one sentence.
- Why only the pain produces it.
- Where it can be read (the source, by name).
- How many accounts, roughly.
- The sub-signal, if there is one.
- What I should check by hand before trusting it: ten accounts to look at.

After I agree, add it to `icp.md` with the date and the deals it came from.

## Rules

- One signal, not five. A list built on five weak signals is a basic list.
- If no trait passes the three tests, say so. Stay on the basic track and
  run more rounds.
